Customer Accounts microservice capstone project.

REST API: POST/GET `/accounts`, GET/PUT/DELETE `/accounts/<id>`.
The application listens on port 8080.

CI workflow: `.github/workflows/ci-build.yaml`.
Security: Talisman security headers and CORS in `service/__init__.py`.
Kubernetes manifests are under `kubernetes/`.
